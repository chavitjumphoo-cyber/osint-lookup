SYNINT v5
github.com/gs-ai/SYNINT
Local-first multi-agent OSINT framework ที่ใช้ระบบ 46+ agents ทำงานแบบ pipeline พร้อม forensic runtime และ chain-of-custody logging
  • Timeline Reconstruction — สร้าง timeline จากหลักฐาน
  • Archive Collection — รวบรวมจาก Wayback Machine, Common Crawl
  • Entity Resolution — เชื่อมโยงตัวตนข้ามแหล่งข้อมูล
  • Relationship Graph — วิเคราะห์ความสัมพันธ์และ centrality
  • Forensic Ledger — append-only audit trail
🤖
OSINT-D2
github.com/Doble-2/osint-d2
Agentic AI investigation platform ที่ใช้ ReAct reasoning loop ให้ LLM ตัดสินใจเลือกเครื่องมือและต่อยอดการสืบสวนเอง
  • Identity Triangulation — เชื่อมโยง username, email, avatar, bio
  • 6D Cognitive Profiling — Identity, Geo, Psychology, Tech, Ideology, OpSec
  • Avatar Comparison — perceptual dHash matching
  • Stylometry Analysis — character n-gram writing style
  • Trust Anchors — weighted scoring จากแหล่งที่เชื่อถือ
  • PDF Dossiers — รายงานสไตล์เอกสารลับ
